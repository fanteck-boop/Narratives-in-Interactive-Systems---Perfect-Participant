# The Perfect Participant

A VR experience for Meta Quest (course project, Narratives in Interactive Systems 2026, AAU).
A polite narrator guides you through a psychology experiment and reframes everything you do as cooperation. About 15 to 20 minutes.

**The game scene is `Assets/Scenes/Lab.unity`.**

## Requirements
- **Unity 6000.6.0f1** (install it through Unity Hub, exactly this version).
- **Git** and **Git LFS** (audio, textures and models live in LFS).
- To play in a headset: the Unity modules **Android Build Support** with **OpenJDK** and **Android SDK & NDK Tools**, plus a Meta Quest with developer mode on.

## Setup
1. Clone and pull the LFS files:
   ```
   git clone https://github.com/fanteck-boop/Narratives-in-Interactive-Systems---Perfect-Participant.git
   cd Narratives-in-Interactive-Systems---Perfect-Participant
   git lfs install
   git lfs pull
   ```
2. In Unity Hub: **Add > Add project from disk**, pick the cloned folder, and open it with 6000.6.0f1. The first import takes a few minutes.
3. In the Project window open **Assets > Scenes > Lab**.

If the scene looks wrong or is missing, rebuild it from the menu **Perfect Participant > Build Lab Scene**. The scene is generated by code (`Assets/_Project/Scripts/Editor/BuildLabScene.cs`), so never edit `Lab.unity` by hand; change the builder and rebuild.

## Play on the PC (no headset)
Open `Lab`, press **Play**, click in the Game view to capture the mouse.

| Key | Action |
|---|---|
| Space / Enter | Start (on the content note screen) |
| T | Toggle seated mode (on the content note screen) |
| W A S D, mouse | Walk and look |
| E | Grab what the crosshair points at. While holding: tap E to put down, hold E to charge a throw |
| Space | Throw what you hold |
| Mouse wheel / R | Turn what you hold (spin / tip toward you) |
| F | Press a button |
| C | Crouch (next to a chair: sit) |
| Q | Hand behind your head |
| Esc | Release the mouse |
| F1 | Debug panel (jump to a test, force outcomes, time scale, restart) |

## Play in the Quest
1. Install the Android modules in Unity Hub (**Installs > 6000.6.0f1 > Add modules**).
2. Turn on developer mode for the headset in the Meta Horizon app, connect it by USB and allow USB debugging in the headset.
3. In Unity: menu **Perfect Participant > Configure Quest Build** (switches to Android and sets OpenXR, IL2CPP, ARM64).
4. **File > Build Profiles > Android**, pick the Quest under Run Device, **Build And Run**.

In the headset: trigger to start, A/X to toggle seated mode on the content note screen. Left stick walks, right stick turns, grip grabs, poke buttons with your finger.

Not tested on a device yet (see `HANDOFF.md`).

## Before playtesting with people
Keep the content note on (`CardDisplay > Show Content Note`). Session logs (CSV) are written to `Application.persistentDataPath`.

## Tests
Close the editor first, then:
```
"C:\Program Files\Unity\Hub\Editor\6000.6.0f1\Editor\Unity.exe" -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -assemblyNames PerfectParticipant.Tests.EditMode -testResults results.xml
```
Or in the editor: **Window > General > Test Runner > EditMode > Run All**.
